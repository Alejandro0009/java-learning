# Java Learning Repository

Este repositorio documenta mi proceso de aprendizaje en **Java**, recopilando
programas, ejercicios y proyectos desarrollados a lo largo de mi formación.

El objetivo es construir una base sólida en Java, avanzar progresivamente hacia
un nivel intermedio–avanzado y dejar evidencia clara y organizada del proceso de aprendizaje.

---

## Objetivo del repositorio

- Aprender y dominar los fundamentos del lenguaje Java
- Desarrollar pensamiento lógico y estructurado
- Comprender a profundidad la Programación Orientada a Objetos
- Aplicar conceptos intermedios y avanzados del Core de Java
- Documentar aprendizajes, errores comunes y buenas prácticas
- Construir un portafolio técnico claro y escalable

Este repositorio se mantiene en constante evolución conforme avanzo en mi formación.

---

## Estructura del repositorio

El contenido está organizado por áreas y niveles de complejidad:

- **fundamentals/**  
  Fundamentos de programación: variables, condicionales, bucles, arreglos y matrices.

- **oop/**  
  Programación Orientada a Objetos: clases, objetos, encapsulación, herencia,
  polimorfismo, abstracción, interfaces y enums.

- **core-java/**  
  Componentes esenciales de Java: colecciones, genéricos, excepciones, streams,
  lambdas, manejo de fechas y utilidades del lenguaje.

- **jvm-memory/**  
  Funcionamiento interno de Java: JVM, manejo de memoria, heap, stack,
  garbage collector y class loading.

- **concurrency/**  
  Programación concurrente y multihilo: threads, sincronización,
  executors y colecciones concurrentes.

- **io/**  
  Entrada y salida de datos: manejo de archivos, NIO, serialización y deserialización.

- **testing/**  
  Pruebas y calidad de código: unit testing con JUnit y buenas prácticas de testing.

- **design-patterns/**  
  Patrones de diseño y principios de software: Singleton, Factory, Builder,
  Observer y principios SOLID.

- **tooling/**  
  Herramientas del ecosistema Java: Maven, Gradle, gestión de dependencias y logging.

- **projects/**  
  Proyectos prácticos que integran múltiples conceptos del lenguaje.

- **advanced-topics/**  
  Temas adicionales: JDBC, conexión a bases de datos, parsing de datos,
  networking básico y otros conceptos avanzados.

- **notes/**  
  Apuntes, resúmenes, errores comunes, buenas prácticas y reflexiones del aprendizaje.

---

## Metodología de aprendizaje

- Estudio progresivo por niveles
- Ejercicios prácticos y código funcional
- Enfoque en entender el *por qué* del código
- Documentación de errores y soluciones
- Refactorización conforme se adquieren nuevos conocimientos
